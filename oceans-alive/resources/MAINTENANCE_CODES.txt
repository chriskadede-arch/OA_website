CODE 2: .HTACCESS - ENABLE MAINTENANCE MODE
Add this to your .htaccess file on GoDaddy
============================================================

RewriteEngine On
RewriteCond %{REQUEST_URI} !^/maintenance\.html$
RewriteRule ^(.*)$ /maintenance.html [R=302,L]


============================================================
CODE 3: .HTACCESS - DISABLE MAINTENANCE MODE
To turn OFF maintenance, add # before each line:
============================================================

# RewriteEngine On
# RewriteCond %{REQUEST_URI} !^/maintenance\.html$
# RewriteRule ^(.*)$ /maintenance.html [R=302,L]


============================================================
GODADDY UPLOAD STEPS:
============================================================

1. Login to GoDaddy → My Products → Manage Web Hosting
2. Click "cPanel Admin"
3. Click "File Manager"
4. Navigate to "public_html" folder
5. Upload TWO files:
   - maintenance.html (copy CODE 1 above)
   - logo.png (from Partners Logos folder)
6. Edit .htaccess (or create new if doesn't exist)
7. Add CODE 2 to .htaccess
8. Save
9. Test in incognito browser
