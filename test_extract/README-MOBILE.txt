OCEANS ALIVE PRESENTATION - MOBILE INSTRUCTIONS
===============================================

HOW TO VIEW ON MOBILE:

1. EXTRACT THE ZIP FILE FIRST
   - Do NOT open the HTML file directly from the ZIP
   - Extract all files to a folder on your phone
   - Make sure both the HTML file and "public" folder are extracted

2. FILE STRUCTURE AFTER EXTRACTION:
   Your folder should look like this:

   📁 OceansAlive-Presentation/
      📄 oceans-alive-MOBILE.html
      📄 README-MOBILE.txt
      📁 public/
         📄 logo.png
         📁 images/
            📁 gallery/
               📄 oceanculturelife.jpg
               📄 communities.jpg
               📄 (and other images...)

3. OPEN THE HTML FILE
   - Use Chrome, Safari, or Firefox browser
   - Navigate to the extracted folder
   - Tap on "oceans-alive-MOBILE.html" to open
   - Images should now load correctly

TROUBLESHOOTING:

❌ Images not showing?
   → Make sure you extracted the ZIP completely
   → Check that the "public" folder is next to the HTML file
   → Try a different mobile browser (Chrome recommended)

❌ Layout broken?
   → Rotate your phone to portrait mode
   → Refresh the browser page
   → Clear browser cache and reload

NAVIGATION:
- Swipe left/right to change slides
- Use the arrow buttons in bottom-right corner
- 14 total slides

For best experience, view in landscape mode on tablets.
